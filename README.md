# 📝 To-Do List App  

## 📌 Description  

- A simple and responsive To-Do List Application  
- Built using HTML, CSS, and JavaScript  
- Helps users manage daily tasks efficiently  
- Clean and user-friendly interface  

---

## 🚀 Live Demo  

- 🔗 https://kumar-sudhakar.github.io/To_Do_List_App/  

---

## 📌 Features  

- ➕ Add new tasks  
- 🗑️ Delete tasks  
- ✅ Mark tasks as completed  
- 📱 Fully responsive design (mobile + desktop)  
- ⚡ Simple and easy-to-use interface  

---

## 🛠️ Tech Stack  

- HTML5 – Structure  
- CSS3 – Styling  
- JavaScript (ES6) – Functionality  

---

## 📂 Project Structure  

- To_Do_List_App/  
  - index.html  
  - style.css  
  - script.js  

---

## ⚙️ How It Works  

- User enters a task  
- Task is added to the list  
- User can mark task as completed  
- User can delete task anytime  

---

## 💻 Run Locally  

- git clone https://github.com/kumar-sudhakar/To_Do_List_App.git  
- cd To_Do_List_App  
- open index.html
